# geosupport-docker v2.0

Dockerfiles for installing, configuring and using the NYC Department of City Planning's Geosupport application from a Docker container.

## NEWS

The NYC Department of City Planning has announced that `Geosupport 26b_26.2` will become available on Tuesday, May 19th. This release features updated NYPD police patrol borough data in the Bronx.

### May 19, 2026
